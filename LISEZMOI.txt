RÉGLAGES SERVO — version hors ligne
====================================

Contenu
-------
index.html                  Le site complet (un seul fichier). Le catalogue est déjà dedans :
                            85 moteurs (Schneider SH3 / ILM / BMP, Interroll DM), 2271 réducteurs
                            (Neugart, Atlanta, STOBER, SEW, Wittenstein…), 5 variateurs LXM62,
                            et les types de matériel Machine Expert (Dico de l'Auto_Pannel).
                            Aucun projet : chacun crée les siens.
base-reglages-servo.json    Le même catalogue en fichier séparé (sauvegarde / import).
LISEZMOI.txt                Ce fichier.

Utilisation
-----------
1. Dézipper le dossier où tu veux.
2. Ouvrir index.html avec Chrome, Edge ou Firefox (double-clic). Pas besoin d'internet
   (sans internet, la police change, c'est tout).
3. Dans la page, le bouton « ? Aide » en haut à droite explique le parcours :
   projet → dossier élec → réglage des axes → hardware → script Machine Expert.
   Le bouton « ? » à côté de chaque champ dit à quoi il sert et où trouver la valeur.
4. Tout ce que tu ajoutes ou modifies est enregistré dans le navigateur de ce PC.

Sauvegarde et autre poste
-------------------------
- Nouvelle version du fichier index.html : les nouvelles références du catalogue
  (moteurs, réducteurs, variateurs, matériel) s'ajoutent toutes seules à ta base, sans
  toucher à tes projets ni aux fiches que tu as modifiées (« Mettre à jour le catalogue »).
- La base vit dans le navigateur : si tu vides les données du navigateur, elle repart
  du catalogue d'origine contenu dans index.html.
- En bas de page : « Exporter la base » télécharge un fichier .json avec tout
  (projets, axes, catalogues). Fais-le régulièrement.
- « Importer une base » recharge un fichier .json exporté (remplace la base actuelle).
- Pour passer sur un autre PC : exporter ici, importer là-bas.

Dossier électrique
------------------
« Importer le dossier élec » lit le classeur .xlsm dans le navigateur : il n'est ni
enregistré ni envoyé. Seuls les axes (nom, désignation, moteur, variateur) et la liste
du matériel (nom, type, IP, Node-ID) sont gardés dans la base.

Mise en ligne (optionnel)
-------------------------
index.html peut être mis tel quel sur GitHub Pages ou un serveur interne.
Chaque navigateur aura alors sa propre base : utiliser Exporter / Importer pour partager.

Attention
---------
Cette version et la page Claude (artefact) ont chacune leur base, elles ne se
synchronisent pas. Choisir l'une des deux comme référence.

Calcul de UserCurrentLimit
--------------------------
Courant limite = T2B ÷ i ÷ Kt × part autorisée (80 % par défaut)
UserCurrentLimit (%) = Courant limite ÷ Imax moteur × 100 (arrondi en dessous)
Exemple : 500 ÷ 449 ÷ 1,208 × 0,8 = 0,74 A → 0,74 ÷ 17,1 = 4,3 %

des dents, ce qui donne GearIn / GearOut exacts. Seul le T2B des KH est pré-rempli (Mamax).
Pour les autres, ouvre le réducteur et saisis T2B, J_Gear, rendement : la fiche est
alors enregistrée dans ta base.
