Il n'y a rien à compiler : la page charge directement ces fichiers. Modifier un seul
fichier suffit, les autres ne bougent pas.

Quoi modifier, où
-----------------
- Ajouter ou corriger un moteur (brushless ou asynchrone), un
  réducteur, un variateur                                      → catalogue/*.js (une ligne par
  fiche, même champs que dans la page ; le bouton ? de chaque champ dit où trouver la valeur).
  Puis mettre la date du jour dans catalogue/version.js (facultatif, c'est l'affichage).
- Ajouter un mot au dictionnaire E/S                           → app/dictionnaire_es.js (IO_SEED).
- Changer le script Machine Expert généré                      → machine-expert/modele_*.js.
- Changer un calcul, un onglet, l'import du dossier            → app/app.js.
- Changer l'aspect                                             → app/style.css.
Pour une modification faite dans la page (fiche ajoutée dans Catalogue › …), elle reste dans la
base du navigateur ; pour la partager avec tout le monde, la recopier dans catalogue/*.js.

Utilisation
-----------
1. Dézipper le dossier où tu veux, garder les sous-dossiers.
2. Ouvrir index.html avec Chrome, Edge ou Firefox (double-clic). Pas besoin d'internet
   (sans internet, la police change, c'est tout).
3. Dans la page, « ? Aide » en haut à droite explique le parcours :
   projet → dossier élec → réglage des axes → hardware → script Machine Expert.
4. Tout ce que tu ajoutes ou modifies dans la page est enregistré dans le navigateur de ce PC.

Sauvegarde et autre poste
-------------------------
- Nouvelle version des fichiers : les fiches nouvelles ou modifiées du catalogue s'ajoutent
  toutes seules à ta base, sans toucher à tes projets ni aux fiches que tu as modifiées
  (« Mettre à jour le catalogue » en bas de page le refait à la demande).
- La base vit dans le navigateur : si tu vides les données du navigateur, elle repart
  du catalogue livré.
- En bas de page : « Exporter la base » télécharge un .json avec tout (projets, axes,
  catalogues). Fais-le régulièrement. « Importer une base » le recharge (remplace la base).
- Pour passer sur un autre PC : exporter ici, importer là-bas.

Mise en ligne (GitHub Pages)
----------------------------
Déposer le dossier tel quel (index.html à la racine du site, avec app/, catalogue/ et
machine-expert/). Modifier un fichier sur GitHub suffit : la page le charge au prochain
rechargement (Ctrl+F5 si le navigateur garde l'ancien). Chaque navigateur a sa propre base :
Exporter / Importer pour partager des projets.

Dossier électrique
------------------
« Importer le dossier élec » lit le classeur .xlsm dans le navigateur : il n'est ni
enregistré ni envoyé. Seuls les axes (nom, désignation, moteur, variateur), la liste
du matériel (nom, type, IP, Node-ID) et la référence des moteurs asynchrones sur ATV320
sont gardés dans la base. Les données constructeur (plaque moteur : puissance, tension,
IN, vitesse, cos φ) viennent toujours du catalogue, jamais du dossier, qui peut se
tromper : ce que le dossier indique ne sert qu'à signaler un écart.

Calcul de UserCurrentLimit
--------------------------
Courant limite = T2B ÷ i ÷ Kt × part autorisée (80 % par défaut)
UserCurrentLimit (%) = Courant limite ÷ Imax moteur × 100 (arrondi en dessous)
Exemple : 500 ÷ 449 ÷ 1,208 × 0,8 = 0,74 A → 0,74 ÷ 17,1 = 4,3 %

Catalogue SEW : les rapports (KH19/29/39/49, K, R, S, F, W série 7) viennent du tableau
des dents, ce qui donne GearIn / GearOut exacts. Seul le T2B des KH est pré-rempli (Mamax).
Pour les autres, ouvre le réducteur et saisis T2B, J_Gear, rendement : la fiche est
alors enregistrée dans ta base.
