Réglages Servo

Comment ça marche

1 · Le projet

Un projet = une machine. Crée-le avec + Projet, puis Importer le dossier élec (.xlsm) : il crée les axes brushless (nom, désignation, moteur, variateur) et le matériel (ATV320, TM5, Ethernet/IP). Le fichier est lu dans ton navigateur, jamais enregistré. Tu peux aussi ajouter un axe à la main.

2 · Les réglages

Onglet Axes : pour chaque axe, choisis le moteur et le réducteur puis décris la charge. Le panneau de droite donne ce qu’il faut saisir dans le variateur (J_Load, UserCurrentLimit, arrêt d’urgence, gains de départ) et signale ce qui dépasse le réducteur. Une attention examinée s’acquitte (avec un motif) : l’axe passe au vert, elle reste listée en gris. Un danger ne s’acquitte pas.

3 · Le hardware

Onglet Brushless : ordre Sercos, LXM62 ou ILM62, codeur, carte IO. Onglet ATV320 : Node-ID, Optional device, heartbeat (les réglages du variateur, ACC, DEC…, restent gérés en Modbus par le programme), et la plaque du moteur asynchrone de chaque ATV320 (NPR, UNS, NCR, FRS, NSP, COS, ITH) d’après sa fiche dans Catalogue › Moteurs, avec le contrôle du calibre du variateur ; le dossier ne donne que la référence (les données constructeur viennent du catalogue de l’outil, jamais du dossier, et ce qu’il indique sert de contrôle). Matériel du projet : le reste (alimentations, îlots TM5, Ethernet/IP). Chaque îlot TM5 commence par sa carte TM5SPS3 (PS3, alimente la tête et le bus TM5) : l’outil la place ou l’ajoute ; les PS1 / PS2 (nouveau segment de puissance) restent où le dossier les met.

4 · Machine Expert

Script Machine Expert génère un script Python : il crée le hardware qui manque (jamais de suppression), écrit les réglages des axes avec une confirmation avant chacun, et tient à jour une liste de paramètres. Rapport dans Documents.

Noms dans Machine Expert

DRV_MT1 variateur de l’axe MT1 · LE_MT1 son codeur logique · IO_MT1 sa carte IO · ATV320_M3 variateur CANopen du moteur M3 · FIELDBUS_1 tête d’îlot TM5 · PS_1 sa carte d’alimentation (TM5SPS3, « PS3 »). Le modèle de chaque nom se voit et se change dans Catalogue › Matériel (« Nom dans l’automate »), ou pour un projet avec « Renommer » dans Matériel du projet. Le script reconnaît un appareil déjà présent sous un autre nom (même parent, même référence) et le garde.

Unités

Units = unité de l’axe dans Machine Expert (mm ou °) ; FeedConstant = déplacement pour un tour de sortie du réducteur. Inerties en kg·cm² (1 kg·m² = 10 000 kg·cm²). T2B = couple max du réducteur, T2N nominal, T2Not arrêt d’urgence.

Entrées / sorties

Onglet E/S du projet : chaque désignation du dossier (« Vérin 1 monter baisser lame ») devient le nom de variable automate (xV1_raisingUp_Blade, xV1_raisingDown_Blade pour un distributeur bistable, un seul nom pour un monostable, un par état pour un capteur). Les mots et leurs traductions se règlent dans Catalogue › Dictionnaire E/S, un nom se corrige à la main dans le projet.

Les données

Les catalogues (moteurs, réducteurs, matériel, dictionnaire E/S) sont communs à tous les projets. Le bouton ? à côté d’un champ dit où trouver la valeur. En mode hors ligne, la base vit dans ce navigateur : exporte-la régulièrement.

Chargement de la base…
Mode hors ligne · la base (projets, axes, catalogues) vit dans ce navigateur. Exporte-la régulièrement : c’est ta sauvegarde, et le moyen de la passer sur un autre poste.
