Réglages Servo

Comment ça marche

1 · Le projet

Un projet = une machine. Crée-le avec + Projet, puis Importer le dossier élec (.xlsm) : il crée les axes (Lexium 62 et ATV320, avec nom, désignation, moteur, variateur) et le matériel (ATV320, TM5, Ethernet/IP). Le fichier est lu dans ton navigateur, jamais enregistré. Tu peux aussi ajouter un axe à la main (+ Brushless, + ATV320).

2 · Les axes

Onglet Axes : la liste de gauche (un point vert, orange ou rouge par axe), le formulaire au milieu, le résultat à droite. Pour chaque axe, choisis le moteur et le réducteur puis décris la charge. Lexium 62 : le panneau donne ce qu’il faut saisir dans Machine Expert (Mechanic, Control loop, General) et trois voyants (couple réducteur, rapport d’inertie, limite de courant). ATV320 : HSP / LSP / ITH / CLI à régler en Modbus et la plaque du moteur. Une attention examinée s’acquitte (avec un motif) : l’axe passe au vert, elle reste listée en gris. Un danger ne s’acquitte pas.

3 · Machine Expert

Onglet Machine Expert : ce que le script crée et règle. Lexium 62 : ordre Sercos, LXM62 ou ILM62, codeur, carte IO. ATV320 : Node-ID, Optional device, heartbeat, et la plaque de chaque moteur (NPR, UNS, NCR, FRS, NSP, COS, ITH) d’après sa fiche du catalogue, jamais d’après le dossier (qui sert de contrôle). Matériel du projet : alimentations, îlots TM5, Ethernet/IP ; chaque îlot TM5 commence par sa carte TM5SPS3 (PS3), que l’outil place ou ajoute.

4 · Bilan & script

Onglet Bilan & script : tous les axes sur une page (à relire), puis Générer le script : un script Python qui crée le hardware qui manque (jamais de suppression), écrit les réglages des axes avec une confirmation avant chacun, et tient à jour une liste de paramètres. Rapport dans Documents. Exporter (Excel) : un onglet par axe.

Noms dans Machine Expert

DRV_MT1 variateur de l’axe MT1 · LE_MT1 son codeur logique · IO_MT1 sa carte IO · ATV320_M3 variateur CANopen du moteur M3 · FIELDBUS_1 tête d’îlot TM5 · PS_1 sa carte d’alimentation (TM5SPS3, « PS3 »). Le modèle de chaque nom se voit et se change dans Catalogue › Matériel (« Nom dans l’automate »), ou pour un projet avec « Renommer » dans Matériel du projet. Le script reconnaît un appareil déjà présent sous un autre nom (même parent, même référence) et le garde.

Unités

Units = unité de l’axe dans Machine Expert (mm ou °) ; FeedConstant = déplacement pour un tour de sortie du réducteur. Inerties en kg·cm² (1 kg·m² = 10 000 kg·cm²). T2B = couple max du réducteur, T2N nominal, T2Not arrêt d’urgence.

Entrées / sorties

Onglet E/S du projet : chaque désignation du dossier (« Vérin 1 monter baisser lame ») devient le nom de variable automate (xV1_raisingUp_Blade, xV1_raisingDown_Blade pour un distributeur bistable, un seul nom pour un monostable, un par état pour un capteur). Les mots et leurs traductions se règlent dans Catalogue › Dictionnaire E/S, un nom se corrige à la main dans le projet.

Les données

Les catalogues (moteurs, réducteurs, variateurs, matériel, dictionnaire E/S) sont communs à tous les projets ; les listes sont repliées par marque et par série, une recherche déplie tout. Le bouton ? à côté d’un champ dit où trouver la valeur. En mode hors ligne, la base vit dans ce navigateur : exporte-la régulièrement.

Chargement de la base…
Mode hors ligne · la base (projets, axes, catalogues) vit dans ce navigateur. Exporte-la régulièrement : c’est ta sauvegarde, et le moyen de la passer sur un autre poste.
